# theDĀW Studio · v0.1

Статический кликабельный прототип редакционного сервиса theDĀW.

## Как запустить

Откройте `index.html` двойным щелчком в браузере. Для публикации на GitHub Pages загрузите `index.html` в корень репозитория и в Settings → Pages выберите Deploy from a branch → main / (root).

## Что работает

- лента из **явно вымышленных** демонстрационных новостей;
- ручное добавление новостей;
- создание и редактирование черновиков Instagram/TikTok;
- сохранение ссылок на медиа с отметкой о правах;
- выбор между тремя демонстрационными визуальными макетами;
- статус «Готово к публикации»;
- локальное хранение в браузере (`localStorage`).

## Что пока не работает

Нет подключения к Telegram, Canva, AI, TikTok, Instagram; нет скачивания видео, серверной базы или настоящей публикации. Макеты демонстрационные, не копируют реальный фирменный стиль.

## Безопасность

Никогда не вставляйте API-ключи Canva, Instagram, TikTok или AI в этот HTML-файл. Для OAuth/API нужен backend.
