# theDĀW Studio

Редакционный сайт: новости → черновики → Gemini → оформление → MP4 / Instagram / TikTok.

## Запуск

Из корня проекта: `python3 -m http.server 8000`, затем открыть `http://localhost:8000`.
Открытие HTML двойным щелчком не заменяет HTTP-сервер: загрузка `news.json` и браузерные API могут ограничиваться.
Продакшен размещается на GitHub Pages из `main`.

## Архитектура и границы

- `index.html`: клиент, редактор, canvas / MediaRecorder, экспорт видео, API-запросы.
- `news.json`, `sources.json`, `scripts/`: сбор RSS / HTML / публичных Telegram-каналов через GitHub Actions.
- `https://thedaw-ai.lunarinkee.workers.dev`: внешняя зависимость. Клиент использует авторизацию, Gemini, Instagram, TikTok и планировщик. **Исходника Worker, миграций D1 и конфигурации R2 в этом репозитории нет.**
- Черновики, подписи, одобрения, корзина и дизайн сохраняются локально в этом браузере. Между устройствами они не синхронизируются. При ошибке сохранения появляется кнопка резервной копии.
- Сессия редактора хранится в `sessionStorage` вкладки. На другом устройстве нужен отдельный вход. Проверка доступа и хранение токенов интеграций должны выполняться Worker.
- `tools/tiktok-studio-upload.mjs`: отдельный локальный помощник; инструкция в `tools/README-tiktok-studio.md`.

Наличие клиентского вызова не доказывает, что интеграция настроена в Cloudflare. Подробности и приоритеты: [AUDIT.md](AUDIT.md).

## Проверки

Без зависимостей и внешних API:

```sh
node --test tests/frontend.test.cjs
node --check tools/tiktok-studio-upload.mjs
python3 -m unittest discover -s scripts -v
```

Браузерная проверка: установить Playwright в локальное окружение (`npm install --no-save playwright`), затем `npx playwright install chromium` и `node tests/browser.cjs`. Тест запускает локальный сервер, подменяет все внешние API и не публикует материалы. Проверяет вход, редактирование, сохранение подписей, обработку нехватки хранилища и ширины 375/768/1440 px. Снимок сохраняется во временную папку ОС.

## Секреты

Не помещать ключи и пароли в HTML, JSON, Git или отчёты. Секреты интеграций настраиваются только в Cloudflare. Не передавать их в чат. Менеджер источников поддерживает GitHub-токен в памяти вкладки; закрывайте вкладку после использования. Серверный обмен с GitHub предпочтительнее для следующего этапа архитектуры.

## Обновлённый интерфейс

`studio.css` и `studio.js` задают оформление по референсам, верхнюю навигацию, dashboard, календарь, заметки, сводку аналитики и раскладку редактора. Календарь загружает существующую очередь; заметки локальные. Превью canvas видно справа, на телефоне переносится ниже. Существующие обработчики экспорта и публикации сохранены.
